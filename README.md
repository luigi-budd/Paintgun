Paintgun is a work-in-progress Splatoon 3 inspired mod for Sonic Robo Blast 2.
Paintgun is best played with [SRB2edit](https://github.com/luigi-budd/SRB2-edit)

Renders made by @supeki

Sounds from Splatoon 3

# How to compile

Download the mod/ folder and open the directory in SLADE. Press "Archive" -> "Build Archive" and save the file as a PK3.
